# Student Portal Guide

The Student Portal is the primary interface for learners interacting with the Naan Mudhalvan Mock Interview Platform.

## Navigation
The portal features a premium Framer Motion powered Sidebar containing:
- **Dashboard**: High-level overview of solved problems, upcoming mock interviews, and study hours.
- **Interviews**: Access to scheduled and past mock interviews.
- **Practice & Question Bank**: Direct integration with the Judge0 coding sandbox.
- **Progress & Reports**: Visualized analytics mapping skill progression.

## Permissions
Students **CAN**:
- View, search, filter, and bookmark questions.
- Execute code via Judge0.
- View their own reports and update their profile.

Students **CANNOT**:
- Edit or delete questions.
- Access other students' data.
- Manage interview templates.
