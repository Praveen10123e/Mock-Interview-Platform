# Faculty Portal Guide

The Faculty Portal empowers educators to manage student cohorts and interview resources.

## Navigation
- **Dashboard**: High-level statistics on student throughput, interview completion rates, and active cohorts.
- **Students**: Direct access to student performance reports and KPIs.
- **Question Bank**: Advanced CRUD interface for managing the global pool of assessment questions.
- **Templates**: Builders for creating standardized interview blueprints.

## Permissions
Faculty **CAN**:
- Perform all Student actions.
- Create, edit, and delete questions.
- Import bulk datasets for question banks.
- Create and assign Interview Templates.
- Monitor global student analytics.
