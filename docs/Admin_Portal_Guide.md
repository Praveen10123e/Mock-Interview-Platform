# Admin Portal Guide

The Admin Portal is the overarching command center for the Naan Mudhalvan platform.

## Navigation
- **Dashboard**: System health, active node tracking, and dataset size monitoring.
- **Users**: Complete role and permission management.
- **Datasets**: Ingestion jobs and duplicate detection tools.
- **System**: Gateway and Judge0 configuration interfaces.

## Permissions
Administrators **CAN**:
- Perform all Faculty actions.
- Approve or reject Question Bank submissions.
- Manage global user roles (elevating students to faculty).
- Audit system logs and access platform analytics.
